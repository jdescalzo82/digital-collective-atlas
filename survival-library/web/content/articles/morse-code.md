Morse code can be sent by light, sound, radio, tapping on pipes or walls, or flag. The *Toolkit* page translates text to Morse and flashes it on your screen or beeps it.

## SOS

**· · · — — — · · ·** sent as one continuous signal with no gaps between letters. Repeat with a long pause.

## Timing

- Dot = 1 unit. Dash = 3 units.
- Gap inside a letter = 1 unit. Between letters = 3 units. Between words = 7 units.
- Beginners: 1 unit ≈ 0.2–0.3 seconds by flashlight.

## Useful signals

| Signal | Meaning |
|---|---|
| AR (· — · — ·) | End of message |
| K (— · —) | Go ahead / over |
| R (· — ·) | Received |
| ········ (8 dots) | Error |
| CQ | Calling anyone |
| QTH | My location is… |

## Learning tips

Learn by **sound rhythm**, not by counting dots: "dit-dah" for A, "dah-dit-dit-dit" for B. Start with E T I A N M S O — the most common letters.
